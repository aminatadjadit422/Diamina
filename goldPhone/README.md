## 🚀 Démarrage rapide (GitHub Pages)

```bash
# Cloner le dépôt
git clone https://github.com/votre-username/goldPhone.git
cd goldPhone

# Ouvrir localement
open index.html
```

### Déployer sur GitHub Pages
1. Aller dans **Settings → Pages**
2. Source : **GitHub Actions** (ou `Deploy from branch → main`)
3. Le site est automatiquement déployé à chaque push sur `main`
